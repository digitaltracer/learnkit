- Difficulty: `easy`
- Problem: Given a string, determine whether it reads the same forwards and backwards. Teach the two-pointer technique: one pointer at each end, compare, then move both inward until they meet.
- Walkthrough example: the string `"racecar"` as a 7-cell array of characters. Compare from both ends inward; all pairs match, so it is a palindrome.
